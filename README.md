# My Portfolio — FinTech Professional Edition

Eight-page responsive Editorial + Digital Studio portfolio for internship applications.

## Open and edit
1. Extract the ZIP archive.
2. Open `index.html` locally, or open this folder in Visual Studio Code.
3. Edit the HTML files. Each page contains its own embedded CSS and JavaScript.
4. Keep the `assets/` directory next to the HTML files.
5. To publish via GitHub, copy these files into your cloned repository, review changes, then commit and push.

## Included
- index.html — redesigned internship-focused hero and recruiter shortcuts
- about.html — background and interests
- projects.html — experience-based work cards with context and contributions
- project-detail.html — structured website support case study with evidence boundaries
- experience.html — scroll-progress timeline with milestone jump links
- skills.html — keyboard-accessible interactive skills explorer
- education.html — qualifications, awards and recruiter CTA
- contact.html — email, LinkedIn, résumé and mailto form
- assets/isaac-portrait.png and assets/isaac-lam-resume.pdf

## Features
- Light/dark themes with saved preference
- Low-opacity moving background, restrained hover/entrance animations
- Mobile/tablet responsive layouts and reduced-motion support
- Self-contained SVG favicon, per-page SEO description, Open Graph tags
- Skip-to-content, keyboard navigation and visible focus styles
- No fabricated metrics, client outcomes, or fake financial data

## Notes
- The contact form opens an email draft; it is not a server-backed form.
- Add approved client screenshots and verified outcomes when available.
- Social sharing metadata intentionally omits a canonical URL or image until the final public domain is confirmed.
- Test the site in your preferred browser and on mobile before publishing.
