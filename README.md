# Isaac Lam — Editorial + Digital Studio | Final Portfolio

This is the complete, updated eight-page portfolio in the selected Editorial + Digital Studio direction.

## Getting started
Open `index.html` in a modern browser. All HTML pages contain their own CSS and JavaScript. No build process or paid dependency is required.

## Pages
- index.html — Home, professional introduction, selected work, perspective and contact CTA
- about.html — Biography and approach
- projects.html — Work and documented experience
- project-detail.html — Website-support case study
- experience.html — Employment and leadership
- skills.html — Skills and capabilities
- education.html — Education, awards and languages
- contact.html — Contact details and mailto-based message form

## Design
- Premium Swiss-editorial layout with enterprise FinTech visual language
- Muted light and graphite dark themes; system preference and persistent manual toggle
- Responsive desktop/mobile navigation and progress indicator
- Subtle scroll-reveal and hover effects, with reduced-motion support
- Portrait and resume included in `assets/`

## Accuracy and contact form
Project descriptions are grounded in supplied experience and do not invent financial metrics or certifications. The contact form opens an email draft; it does not send messages through a backend. Check dates and details before publishing.

## Publishing
Upload the files to any static hosting service, keeping the `assets` folder alongside the HTML pages. For GitHub Pages, keep `index.html` at the site root.


## Updated visual motion
- Navigation and footer brand: My Portfolio.
- Animated low-opacity (12–16%) background grid, orbits, lines and nodes across every page.
- More prominent hero entrances, project/card hovers, button shimmer and scroll reveals.
- Reduced-motion support retained. All visuals use CSS, no animation libraries.
